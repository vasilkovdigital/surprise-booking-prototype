# Surprise.by — прототип онлайн-бронирования (ТЕСТОВАЯ ВЕРСИЯ)

Минималистичный прототип для проверки логики бронирования. Оплата, Google Calendar и отправка уведомлений **имитируются**.
Стек: Node.js ≥ 22.13, встроенные `node:sqlite` и `http`. **Зависимостей нет, `npm install` не нужен.**

## Запуск

```bash
npm start          # http://localhost:3000 (при первом запуске БД заполняется сама)
npm run seed       # пересоздать БД с тестовыми данными (data/app.db)
npm test           # автопроверка 6 критериев готовности из ТЗ
```
Порт: переменная `PORT`. Файл БД: `DB_PATH`.

## Тестовые аккаунты (пароль у всех: `test1234`)

| Роль | Email | Что это |
|---|---|---|
| Клиент | `client1@test.by`, `client2@test.by` | тестовые клиенты (`is_test`) |
| Партнер А | `partner-a@test.by` | Квадро-Тур: календарь подключен → бронь подтверждается сразу |
| Партнер Б | `partner-b@test.by` | Джип-Туры: только кабинет → ручное подтверждение, уведомления в Telegram + Email |
| Партнер В | `partner-v@test.by` | Гончарная студия: без интеграции → только «Оформить в подарок» |
| Админ | `admin@test.by` | создание партнеров (`/admin`) |

Набор «Выходные на природе» = услуга партнера А или Б (выбор после активации). Партнеры и услуги вымышленные.

## Как проверить (критерии ТЗ)

1. **А:** каталог → «Прокат квадроциклов» → «Купить сейчас» → слот → данные → «Оплатить (тест)». Бронь «Подтверждена», слот пропал из списка.
2. **Б:** то же для джип-тура → «Ожидает подтверждения». В кабинете `partner-b` — «Подтвердить» / «Отклонить» / «Имитировать истечение срока» (→ «Отклонена» + «Возврат (имитация)»). Результат — в «Журнале уведомлений».
3. **В:** у «Мастер-класса» только «Оформить в подарок».
4. **Подарок:** «Оформить в подарок» (одна страница: упаковка, данные, оплата) → код из 12 цифр. «Активировать сертификат» → код → регистрация получателя (дата рождения обязательна) → для набора выбор услуги → слот (только в пределах 3 месяцев) или контакты партнера (у В).
5. **Вместимость:** кабинет партнера → «Услуги» → «Вместимость слота» = 3 → на один слот принимается 3 брони, 4-й нет.
6. **Отмена клиентом:** «Мои брони» → бронь. Если до визита ≥ порога (по умолчанию 24 ч, у партнера настраивается) — «Отменить/Перенести» (отмена → «Возврат (имитация)»); иначе кнопок нет, только контакты «Написать партнеру».

## Что где

- `src/slots.js` — недельный график, закрытия/открытия дат, вместимость
- `src/booking.js` — создание, статусы, отмена/перенос, правила сроков
- `src/gifts.js` — сертификаты, 12-значный код, проверка
- `src/notify.js` — журнал уведомлений (кому, что, по какому каналу)
- `src/routes/*` — экраны: каталог/чекаут/подарок/активация, кабинет партнера, админ

Допущения: корзины нет (один сертификат — один заказ); по умолчанию подтверждение 3 ч и бесплатная отмена 24 ч (таблица `settings`, у партнера переопределяется); если бронь по сертификату отменена/отклонена, сертификат снова становится активным.

## Главная и каталог (ТЗ главной)

Слайдер-карусель (универсальный сертификат, эксклюзив, корпоративный баннер → corp.surprise.by), блок преимуществ, блок «как дарим» (анонимно / менеджером / посылкой / удалённо), каталог с фильтрами (Эксклюзив сверху, категории, бюджет, количество человек, город, повод, пол, возраст, новинки), сортировки (в т.ч. по рейтингу и кэшбэку), бесконечная лента (`/catalog/items`), карточки с избранным, бейджами, кэшбэком с тултипом и сменой фото при наведении, SEO/GEO-текст, блок о компании и FAQ. Фото в прототипе заменены цветными плитками с маркой бренда. Данные витрины (рейтинги, кэшбэк, города) вымышленные.

## Режим прототипа

Обязательность полей форм отключена (кнопку «К оплате» можно нажать с пустыми данными: заказ оформится на демо-покупателя). Строгая проверка: `STRICT_FORMS=1 npm start`. Вошедшему пользователю шаг «Контакты» не показывается.

## Каталог: страницы вместо бесконечной ленты

Каталог листается по 12 карточек на странице (`?page=N`). Фильтры, сортировка и страницы считаются одним модулем `src/catalog-core.js` — и на сервере (первая отрисовка), и в браузере (по `/catalog.json`).

## Статическая демо-витрина (GitHub Pages)

`npm run build:static` собирает папку `docs/` (главная, каталог, карточки, контентные страницы, поиск). Бронь, корзина, оплата и кабинеты ведут на страницу «доступно в полной версии» — они работают только с сервером (`npm start`). `BASE_PATH=/имя-репозитория` задаёт префикс путей.
